# 3 分钟快速入门

> 目标：加 1 个供应商 + 1 把 Key → 健康检测通过 → 推送到已安装后端 → 在工具里发一句测试。

## 1. 启动

```bash
pip install -r requirements.txt
python3 run.py
# 浏览器打开 http://127.0.0.1:8787
```

数据目录：`~/.ai-switch/`（`data.json` 配置，`usage.json` 用量）。

## 2. 四步闭环（Dashboard 会引导）

| 步骤 | 做什么 | 成功标准 |
|------|--------|----------|
| ① 供应商 + Key | **供应商** → 添加，或 **智能导入** | 至少 1 供应商、1 把 Key |
| ② 健康检测 | **全部检测** 或单 Key「检测」 | 至少 1 把 Key 显示正常 |
| ③ 确认后端 | **后端引擎** 看状态 | 需要同步的工具为「已停止/运行中」（不是「未安装」） |
| ④ 推送并验证 | **推送到后端**（会先 Preview）→ 在 OpenCode / Codex 发「hi」 | 工具能正常出字 |

未完成时 Dashboard 会突出四步引导；设置里可「再次显示引导」。

## 3. 推送前看 Preview

点 **推送到后端** 会先列出：

- **将写入**：已安装且未禁用同步的后端 + 配置文件路径  
- **跳过**：未安装 / 同步关 / 只读  

确认后再写入。原则：**宁可少同步，不可错同步**。

## 4. 常用入口

| 场景 | 入口 |
|------|------|
| 批量粘贴 Key | Dashboard / 供应商 → 智能导入 |
| 备份 / 恢复 | Dashboard 导出备份；可设密码加密 |
| 分享整套配置 | 设置 → 配置档案 → 导出（可加密） |
| 排障 | 诊断 → 下载诊断包（无密钥，可贴 Issue） |
| Codex 换供应商 | 后端引擎 → Codex CLI → 供应商 |

# 30 秒演示脚本（录屏用）

> 目标：让观众 10 秒内懂「这是干嘛的」，30 秒内看到「我能用」。  
> 工具：QuickTime / OBS；分辨率 1280×720+；鼠标别抖。

## 开场口播（约 5s）

> 中转 Key 太多，OpenClaw、OpenCode、Codex 配置改到吐？  
> AI Switch：本地 Key 中枢——改一处，推到已安装工具。

## 画面分镜

| 秒 | 画面 | 操作 | 口播 |
|----|------|------|------|
| 0–5 | 浏览器已开 `8787` Dashboard | 指四步引导 | 见上 |
| 5–12 | 智能导入 / 供应商 | 粘贴 1 行 `url + sk-...` → 导入 | 「批量导入，按 URL 自动合并」 |
| 12–20 | Key 行点检测 | 等变绿 / 成功 Toast | 「健康检测，坏 Key 不同步」 |
| 20–28 | 后端页 → 推送 | 打开 Preview → 确认 | 「未安装不写；先 Preview 再推」 |
| 28–35 | （可选）终端 Codex/OpenCode 回 hi | 成功出字 | 「工具侧立刻能用」 |

## 不要做

- 不要念功能清单  
- 不要展示真实完整 Key（导入用假 Key 或只露前 8 位）  
- 不要超过 45 秒；超时就剪

## 标题 / 封面文案

- 中转 Key 太多？一把推到 Codex / OpenCode  
- 本地 AI Key 中枢 · 开源
